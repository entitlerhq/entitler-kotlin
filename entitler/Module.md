# Module Entitler

The official Entitler SDK for Kotlin: check customers' entitlements, record usage, show pricing and
manage subscriptions, from servers on the JVM and from Android apps.

Start with [com.entitlerhq.entitler.EntitlerServer] on a server, or
[com.entitlerhq.entitler.EntitlerClient] in an app.

# Package com.entitlerhq.entitler

The clients, the customer interface, the answers and the errors.
