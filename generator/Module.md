# Module Entitler generator

Two commands for build tooling. `entitler generate` writes a Kotlin source file of typed feature
constants from your Entitler catalogue. `entitler snapshot-keys` writes the public keys that verify
offline snapshots, as JSON for your app to ship.

# Package com.entitlerhq.entitler.generator

The command line entry point and the rendering function build tooling can call.
